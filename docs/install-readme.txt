dsDock 桌面备忘录 — 安装说明

1. 双击 DsDockSetup.exe
2. 在安装向导里选择安装位置（默认 D:\dsDock，可改；不建议装到 C 盘）
3. 勾选项：
   - 创建桌面快捷方式
   - 开机自动启动（也可安装后在托盘右键菜单里开关）
   - 安装完成后立即启动
4. 点「开始安装」

说明
- 程序数据（设置 / 布局 / 便签内容）保存在安装目录的 data\ 下；重复安装只覆盖程序文件，不会删除数据。
- 卸载：运行安装目录里的 Uninstall.cmd，或在「设置 → 应用 → 已安装的应用」里找「桌面备忘录（dsDock）」。
- 运行要求：Windows 10/11 x64 + .NET 8 桌面运行时（本机已装 SDK，也满足）。
- 静默安装（可选，供脚本调用）：
  DsDockSetup.exe --silent --dir "D:\dsDock" [--no-shortcuts] [--no-launch]
- 已知环境注意：从 D:\dshwk001 这类受限目录启动的进程可能被降为低完整性，导致托盘图标注册被系统拒绝；
  本安装包默认装到 D:\dsDock，正是为了避免这个问题。
